# 설계가 바뀐 이유

## 셀 부품 조립에서 예약 공간 중심으로

첫 주에는 셀 예약 범위 표시에서 시작해 저장·포털 정렬·충돌 검사와 생성기를 확장했습니다([전체 이력](PROJECT-HISTORY.md)). 이후 블록 제작 도구에서 셀 기반 배치·삭제와 프리팹 미리보기를 다뤘습니다. 45도 포털을 연결하려고 삼각형 부품과 바닥 마감 방식을 검토하면서, 아트를 셀 조립 규칙에 맞추는 작업이 원래 목적을 흐리고 있다는 점을 발견했습니다.

제가 원한 것은 방이 차지할 범위를 정하고, 그 범위에 맞는 아트를 자유롭게 넣어 생성기에 공급하는 툴킷이었습니다. 그래서 예약 셀과 아트의 책임을 분리하고 두 가지 제작 순서를 모두 지원하도록 방향을 정했습니다.

## 분리된 책임을 하나의 편집 환경으로

공간 제작·아트 적용·게임 규칙 적용을 개념적으로 구분하되, 사용자는 하나의 편집 환경에서 작업하도록 통합했습니다. 방 하나는 BlockData 하나와 아트 프리팹 하나로 구성하며, 아트는 RoomRoot 아래에 배치합니다. 포털도 별도 셀 브러시 대신 아트 편집에서 배치합니다.

포털 위치는 자유롭게 지정하고 Y축 방향은 45도 단위로 제한했습니다. 디자인과 개구부 폭·높이는 공통 규격으로 유지하고, 추가 예약 깊이는 인스턴스별로 수정하도록 했습니다. 같은 디자인과 규격을 사용하는 포털끼리 연결하도록 호환 조건을 명확히 했습니다.

## 필수 생성보다 배치된 요소의 동작 설정

필수 오브젝트를 별도 생성 단계에서 다시 넣기보다, 아트 제작 단계에서 레버나 장치를 배치하고 이후 상호작용 시 실행할 동작을 설정하도록 했습니다. 규칙은 필요한 방에만 추가합니다.

- 상호작용: 게임 입력에서 호출할 이벤트
- 영역 이벤트: 진입·이탈·머무름에 따른 동작
- 조건부 생성: 이미 배치한 대상의 확률별 활성 여부

## 익숙한 조작으로 개선

Unity 카메라 조작과 충돌하는 우클릭 삭제를 제거하고, 한 칸 클릭과 범위 편집을 하나의 입력 흐름으로 정리했습니다. XZ 범위를 드래그한 뒤 놓고 높이를 조정하며, 다음 클릭으로 확정합니다. 별도 편집 높이 슬라이더는 없애고 클릭한 면에서 시작하도록 했습니다.

현재는 매뉴얼을 기준으로 전체 제작 흐름을 직접 사용하며 사용성과 폴리싱 항목을 도출하는 단계입니다. 이 사용성 점검 결과는 아직 완료된 성과로 제시하지 않습니다.
